Confidentialité

Ce que ce site collecte

Ce site n’utilise ni cookies, ni traceurs publicitaires, ni outil de mesure d’audience.

Quand vous nous écrivez

Si vous envoyez un message par le formulaire, nous recevons votre adresse e-mail, votre message et, si vous l’indiquez, votre nom. Nous les utilisons uniquement pour vous répondre et les supprimons quand ils ne sont plus nécessaires.

Vos droits

Vous pouvez à tout moment nous demander de consulter, corriger ou supprimer ce que vous nous avez envoyé, via la page contact.

Changements
